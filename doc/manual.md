# Finch 使用说明

## 操作

| 操作 | 方式 |
| --- | --- |
| 展开目录 | 单击目录，右侧新开一栏 |
| 预览文件 | 单击文件，最右栏显示预览（图片 / PDF 首页 / 视频抓帧 / 文本前 8 KB / 图标）和大小、修改时间，图片还显示分辨率，PDF 显示页数，视频显示时长和分辨率（PDF 用 poppler-utils 渲染，视频用 ffmpegthumbnailer 抓 10% 处的一帧、GStreamer 读元数据，都是 Mint 自带）。名字和大小等信息立即出现，缩略图、分辨率和文本内容在后台读取后填入，慢介质不会卡住窗口。预览内容随窗口伸缩：宽度随栏右侧的剩余空间增长到 720 px，图片 / 文本框的高度随窗口高度在 160–720 px 之间变化 |
| 预览缓存 | 预览图和分辨率 / 页数 / 时长在进程内缓存最近 32 项，再次点选立即出图；PDF 和视频的渲染结果还写入 `~/.cache/thumbnails/xx-large/`（freedesktop 缩略图规范，与 Nemo 共用目录），下次启动直接读取；渲染超过 150 ms 时才显示占位（有 Nemo 生成的小缩略图就用它，否则用文件图标），本地文件直接出完整图；图片不会放大超过原始尺寸。文件修改后缓存自动失效 |
| 打开文件 | 双击、Ctrl+O、Ctrl+↓，或预览栏的"打开"按钮 |
| 栏间移动 | ← → 切换栏，↑ ↓ 选择，Backspace 或 Alt+↑ 回到上一级 |
| 多选 | Ctrl 点击增减，Shift 点击或 Shift+↑↓ 选范围，Ctrl+A 全选。多选时右侧不展开目录，预览栏显示汇总（数量、总大小、前几个名字）；剪切 / 复制 / 拖拽 / 移到回收站 / 删除 / 还原 / 打开都作用于整组，重命名只在单选时可用；右键点在已选中的行上不会打散选区 |
| 前进 / 后退 | 地址栏左侧的 ‹ › 按钮，或 Alt+← / Alt+→。换根目录和在栏里选中目录都算一次位置变化；回退时恢复当时的根目录并逐级重新展开到原来的位置，选中的文件也会重新预览 |
| 快速定位 | 在栏里直接打字按文件名跳转（GTK 自带） |
| 调整栏宽 | 拖动栏右边缘的分隔线，只改这一栏；按住 Shift 拖动则所有栏同步，并作为新栏的默认宽度 |
| 跳转路径 | Ctrl+L 聚焦路径框，输入路径回车 |
| 排序 | 右键菜单或右上角菜单里的"排序方式"：名称 / 修改日期 / 大小 / 类型，"倒序"勾选项反转方向。文件夹始终排在文件前面，倒序只翻转各自组内的顺序；修改日期默认最新在前，大小默认最大在前，类型按 MIME 类型的描述分组、同类按名称。所有栏共用同一设置 |
| 隐藏文件 | Ctrl+H |
| 刷新 | F5（目录有变化时也会自动刷新） |
| 重命名 | 回车、F2 或右键菜单"重命名"，就地编辑（文件默认只选中扩展名之前的部分） |
| 新建文件夹 | 地址栏右侧的按钮或 Ctrl+Shift+N，在当前目录里新建"未命名文件夹"并直接进入改名 |
| 复制 / 剪切 | Ctrl+C / Ctrl+X 或右键菜单，把选中项放进系统剪贴板；和 Nemo 用同一种格式，两边互相粘贴都可以，粘贴到终端里得到的是路径 |
| 粘贴 | Ctrl+V 粘贴到当前目录；右键某个目录则粘贴进该目录，右键文件或空白处粘贴到这一栏的目录。同名时自动改为"xx 副本"、"xx 副本 2"，不覆盖；剪切的内容粘贴一次后剪贴板即清空；复制在后台进行，完成后选中粘贴出来的项 |
| 复制进度 / 取消 | 粘贴和拖拽都在状态栏右侧显示进度：先"正在准备"统计总量，然后显示正在复制的项、已完成 / 总字节数和进度条；多次操作排队执行，标签里注明还有几项等待。点旁边的 ✕ 取消当前这一项：复制到一半的文件会被删掉，跨磁盘移动被取消时源文件保持不动；排在后面的操作照常进行。有操作在进行时关窗口会先确认 |
| 当前目录 | 即标题栏和路径框显示的目录：焦点栏里选中的是目录时就是它，否则是这一栏本身的目录。粘贴、新建文件夹、在终端 / Nemo 中打开都以它为准 |
| 压缩 | 右键菜单"压缩…"（单选或多选均可），填名字、选 zip / 7z / tar.gz / tar.xz，可选填密码，压缩包生成在所选项所在目录，同名时自动加序号。不带密码的 zip 和 tar 用 Python 自带的 zipfile / tarfile 生成；7z 格式和带密码的包交给 `7z` 程序（Mint 自带的 p7zip-full），密码用 AES-256，7z 格式还会把文件名一起加密，zip 的文件名仍可见。注意：7z 运行期间密码会出现在它的命令行参数里，本机其他用户用 ps 能看到，file-roller 也是这样做的。和复制一样在状态栏显示进度、可取消（取消会删掉写了一半的压缩包），完成后选中新压缩包。符号链接按链接本身存入，不跟随 |
| 解压 | 右键压缩包选"解压到此处"（多选时全是压缩包也可以）；压缩包上不再出现"压缩…"，混合选择时则只有"压缩…"。zip / 7z / rar / 单个 .gz .xz 等交给 `7z` 解，tar 及 tar.gz / bz2 / xz 用 Python 的 tarfile 一步解开。先解到旁边的隐藏临时目录：里面只有一项就直接挪出来，多项则装进以压缩包命名的文件夹，不会把文件撒在当前目录，也不覆盖已有文件（同名加"副本"）。遇到加密包会弹框要密码，密码错了再问一次；tar 里指向目录外的条目会被拒绝并提示。进度、取消和复制一样，取消后临时目录即删除 |
| 移到回收站 | 右键菜单或 Delete 键，不确认 |
| 永久删除 | 右键菜单"删除"或 Shift+Delete，会先确认；目录递归删除 |
| 回收站 | 从侧边栏进入 Trash 后，右键菜单变为"还原 / 彻底删除"，空白处可"清空回收站"；Delete 键在这里是彻底删除，不能重命名 |
| 在 Nemo 中打开 / 显示 | 右键菜单，或 F4 在终端中打开当前目录 |
| 标签页 | Ctrl+T 在新标签页打开当前目录，Ctrl+W 关闭当前标签页（最后一个关闭窗口），Ctrl+Tab / Ctrl+PageDown 和 Ctrl+Shift+Tab / Ctrl+PageUp 切换；右键文件夹选"在新标签页中打开"、中键点击文件夹、中键点击侧边栏位置都在后台开新标签页。只有一个标签页时不显示标签栏，标签可拖动排序。每个标签页有自己的栏、预览和前进 / 后退历史；栏宽、隐藏文件、排序方式是全局的，对所有标签页生效。启动时恢复上次打开的所有标签页；命令行给多个目录则各开一个标签页 |
| 拖拽 | 把文件拖到另一栏、某个目录行或侧边栏的位置上即移动过去，按住 Ctrl 为复制；拖到回收站（栏或侧边栏的 Trash）即移到回收站。目标目录行会高亮，整栏作目标时整栏变色；拖回原目录、拖进自身不接受。也可以在 Finch 和 Nemo 等程序之间拖拽 |

左侧是 GTK 自带的"位置"侧边栏，书签、挂载的设备、网络位置都在里面，
和 Nemo 共用同一份书签。每个分区有标题；已挂载的设备名下有一条空间占用条，
悬停显示已用 / 总量，用量超过 90% 变红，F5 会一起刷新。百分比按 `df` 的口径算：
已用 ÷（已用 + 可用），不计文件系统为 root 预留的空间，所以和 `df` 的 Use% 一致；
容量用十进制单位（GB），和 Nemo、磁盘工具相同，比 `df -h` 的 GiB 数字大约 7%。

窗口大小、栏宽、隐藏文件开关、排序方式、打开的标签页保存在 `~/.config/finch/state.json`。

## 没有做的

- 新建文件、复制时同名冲突的询问（现在一律改名为"副本"）
- 缩略图（只有图片在预览栏里显示，列表里是 MIME 图标）
- 搜索
