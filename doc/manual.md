# Finch 使用说明

## 操作

| 操作 | 方式 |
| --- | --- |
| 展开目录 | 单击目录，右侧新开一栏 |
| 预览文件 | 单击文件，最右栏显示预览（图片 / PDF 首页 / 视频抓帧 / 文本前 8 KB / 图标），下面按 Finder 的样子排：粗体文件名，一行灰字写类型和大小（纯文本文档 - 35 kB），然后是"信息"小节，每行左边是项目、右边是值，行间细线隔开：图片的分辨率、PDF 的页数、视频的时长和分辨率，创建时间、修改时间，符号链接的目标（PDF 用 poppler-utils 渲染，视频用 ffmpegthumbnailer 抓 10% 处的一帧、GStreamer 读元数据，都是 Mint 自带）。名字和大小等信息立即出现，缩略图、分辨率和文本内容在后台读取后填入，慢介质不会卡住窗口。预览栏至少和一栏一样宽（选文件和选文件夹时条带伸长的距离相同），内容随窗口伸缩：宽度随栏右侧的剩余空间增长到 720 px，图片 / 文本框的高度随窗口高度在 160–720 px 之间变化 |
| 预览缓存 | 预览图和分辨率 / 页数 / 时长在进程内缓存最近 32 项，再次点选立即出图；PDF 和视频的渲染结果还写入 `~/.cache/thumbnails/xx-large/`（freedesktop 缩略图规范，与 Nemo 共用目录），下次启动直接读取；渲染超过 150 ms 时才显示占位（有 Nemo 生成的小缩略图就用它，否则用文件图标），本地文件直接出完整图；图片不会放大超过原始尺寸。文件修改后缓存自动失效 |
| APK 图标 | Android 安装包（.apk）在预览栏、图标视图和分栏的文件行里显示应用自己的启动图标（分栏里是缩到 16 像素的小图标，列表先用文件类型图标显示出来，后台读到后换上；读过的下次直接显示），不需要安装 Android 工具：直接读包里的 `AndroidManifest.xml` 找到图标的资源号，再到 `resources.arsc` 里查出对应的文件（文件名被混淆成 `res/Qu.xml` 之类也没关系）。位图图标（png / webp）取密度最高的一张，按原始大小显示；自适应图标（前景 + 背景）合成后裁成圆角方形；矢量图标（包括渐变、分组变换、裁剪路径）转成 SVG 渲染，画成 256 像素。同一资源有多个 Android 版本的副本时取最新版本的那份（构建工具给旧版本留的副本是删减过的）。一个包只读这两张表和图标文件，一百多 MB 的包也只要几十毫秒；结果写入缩略图缓存（和 Nemo 共用目录），文件改动后失效。没有图标、图标是这里画不了的类型、或文件损坏时仍显示文件类型图标。预览栏的信息里另有两行："包名"（应用 ID，如 `com.example.app`）和"版本"（版本名加括号里的版本号，如 `4.11.0 (41100)`；只有其中一个就只显示那一个，都没有就没有这一行），同样读自清单，版本名写在资源里（`@string/…`）的也查得出 |
| 打开文件 | 双击、Ctrl+O 或 Ctrl+↓。右键菜单里的"打开"和 Nemo 一样写明默认程序：用 Zed 打开、用图像查看器打开，并带该程序的图标；多选时所有文件的默认程序相同才这样显示，否则（以及文件夹、没有关联程序的文件）只写"打开" |
| 栏间移动 | ← → 切换栏，↑ ↓ 选择，Backspace 或 Alt+↑ 回到上一级 |
| 多选 | Ctrl 点击增减，Shift 点击或 Shift+↑↓ 选范围，Ctrl+A 全选。多选时右侧不展开目录，预览栏显示汇总（数量、总大小、前几个名字）；剪切 / 复制 / 拖拽 / 移到回收站 / 删除 / 还原 / 打开都作用于整组，重命名只在单选时可用；右键点在已选中的行上不会打散选区 |
| 前进 / 后退 | 地址栏左侧的 ‹ › 按钮，或 Alt+← / Alt+→。换根目录和在栏里选中目录都算一次位置变化；回退时恢复当时的根目录并逐级重新展开到原来的位置，选中的文件也会重新预览 |
| 快速定位 | 在栏里直接打字按文件名跳转（GTK 自带），图标视图里同样可以 |
| 图标视图 | 工具栏右侧的两个按钮或 Ctrl+1 / Ctrl+2，整个标签页在分栏和图标网格之间切换，设置对所有标签页生效并保存。图标视图只显示当前文件夹，占满整个区域，没有预览栏（状态栏仍显示选中数量和大小）；从分栏切过来时显示的是当前所在的文件夹（地址栏最后一级，也就是选中文件所在的那一列，不是最左一列），选中的文件保持选中；切回分栏时各列恢复原样，在图标视图里又往下走过的话就从原来的最左一列一路展开到现在的文件夹，走出了那一列则只显示现在的文件夹；后退 / 前进到在分栏里去过的位置时同样显示那个位置所在的文件夹；文件名最多换到三行，再长的末尾省略：双击文件夹进入，退格回上级，前进 / 后退照旧。单击 / Ctrl / Shift 选择、空白处拖框选、Ctrl+A、方向键 / Home / End / PageUp / PageDown、回车重命名（原位弹出输入框）、Delete、右键菜单、中键开新标签页、拖放都和分栏一样。图片有缩略图（Nemo 生成过的直接用，没有的后台生成并写入 `~/.cache/thumbnails/large/`），PDF 和视频只用已有的缓存；APK 显示应用图标（见"APK 图标"）。图标上的徽标和 Nemo 一样：没有写权限的文件和文件夹是一把锁，不可读的是红叉，符号链接是箭头；此外需要密码的压缩包（zip / 7z / rar）也是一把锁（主题有 emblem-locked 就用它，没有就和只读的锁一样）。徽标半个图标大，第一个在右下角，再多的依次放右上、左下（和 GTK 画 GEmblemedIcon 的顺序相同）；一个文件最多一把锁，加密优先于只读，回收站里不标只读。是否加密在后台查（zip 读中央目录里的加密标志，7z / rar 问 `7z l`，连文件名一起加密的 7z 也认得出），结果按文件的修改时间和大小缓存。网格是自己画的（不用 GtkIconView）：格子等大、只画看得见的，三万个文件的目录改窗口大小、滚动、选中都在几十毫秒内 |
| 分栏里的缩略图 | 分栏的文件行里，图片和视频的小图标是文件自己的缩略图（APK 是应用图标），和图标视图用的是同一套缩略图和缓存，缩到 16 像素、保持宽高比。列表先用文件类型图标显示出来，只为看得见的行在后台取缩略图，滚动到哪里取到哪里，所以几万张图片的文件夹打开速度不变；取过的在本次运行中直接显示，目录刷新（文件增删、排序）时已有的缩略图随列表一起出现，不会闪回文件类型图标。图片没有缓存时后台生成并写入 `~/.cache/thumbnails/large/`；视频和图标视图一样只用已有的缓存（Nemo 生成过的，或在 Finch 里选中过、预览栏渲染过画面的——预览栏渲染完，那一行的图标随即换成画面）。文件改动后按新的修改时间重取。读不出来的图片、超过预览大小上限的图片、没有缓存的视频保持文件类型图标 |
| 调整栏宽 | 拖动栏右边缘的分隔线，只改这一栏；按住 Shift 拖动则所有栏同步，并作为新栏的默认宽度 |
| 地址栏 | 和 Nemo 一样有两种样式，并且只显示文件夹：选中文件时地址栏和标题停在它所在的文件夹。默认是按钮式：当前路径的每一级是一个按钮（主目录以内从主目录开始，以外从"文件系统"开始，主目录、图片等特殊目录和回收站带图标），当前位置的按钮按下显示，点其他级即跳转，中键在新标签页打开。分栏视图里跳转不会重排各栏，效果和在栏里点了那个文件夹的节点一样：点的文件夹已经有一栏，就回退到它，右边的栏收起、它里面不留选中项，焦点落在左边选中它的那一栏；点的是比最后一栏更深的一级（往上走后留在栏里的），就从现有的栏逐级展开到它；只有点最左一栏之上的级别（或它在父目录的栏里没有节点，例如隐藏文件夹），以及在图标视图里，才把它单独显示为最左一栏。这些跳转都记入前进 / 后退历史；往上走时更深的几级仍留在栏里，可以再点回去，其中被删除、移走或改名的文件夹在所在目录刷新时自动从栏里去掉；路径太长时两端出现箭头，鼠标滚轮也能滚。点地址栏右边的图标切换成文字输入框（这个状态会记住），再点一次切回。Ctrl+L 临时显示输入框并全选路径，回车跳转或 Escape 后自动变回按钮；输入文件路径则进入其所在目录并选中该文件 |
| 排序 | 右键菜单或右上角菜单里的"排序方式"：名称 / 修改日期 / 大小 / 类型，"倒序"勾选项反转方向。文件夹始终排在文件前面，倒序只翻转各自组内的顺序；修改日期默认最新在前，大小默认最大在前，类型按 MIME 类型的描述分组、同类按名称。所有栏共用同一设置 |
| 隐藏文件 | Ctrl+H |
| 刷新 | F5（目录有变化时也会自动刷新） |
| 重命名 | 回车、F2 或右键菜单"重命名"，就地编辑（文件默认只选中扩展名之前的部分） |
| 新建文件夹 | 地址栏右侧的按钮或 Ctrl+Shift+N，在当前目录里新建"未命名文件夹"并直接进入改名 |
| 复制 / 剪切 | Ctrl+C / Ctrl+X 或右键菜单，把选中项放进系统剪贴板；和 Nemo 用同一种格式，两边互相粘贴都可以，粘贴到终端里得到的是路径 |
| 粘贴 | Ctrl+V 粘贴到当前目录；右键某个目录则粘贴进该目录，右键文件或空白处粘贴到这一栏的目录。同名时自动改为"xx 副本"、"xx 副本 2"，不覆盖；剪切的内容粘贴一次后剪贴板即清空；复制在后台进行，完成后选中粘贴出来的项 |
| 复制进度 / 取消 | 粘贴和拖拽都在状态栏右侧显示进度：先"正在准备"统计总量，然后显示正在复制的项、已完成 / 总字节数和进度条；多次操作排队执行，标签里注明还有几项等待。点旁边的 ✕ 取消当前这一项：复制到一半的文件会被删掉，跨磁盘移动被取消时源文件保持不动；排在后面的操作照常进行。有操作在进行时关窗口会先确认 |
| 当前目录 | 即标题栏和路径框显示的目录：焦点栏里选中的是目录时就是它，否则是这一栏本身的目录。粘贴、新建文件夹、在终端 / Nemo 中打开都以它为准 |
| 压缩 | 右键菜单"压缩…"（单选或多选均可），填名字、选 zip / 7z / tar.gz / tar.xz，可选填密码，压缩包生成在所选项所在目录，同名时自动加序号。不带密码的 zip 和 tar 用 Python 自带的 zipfile / tarfile 生成；7z 格式和带密码的包交给 `7z` 程序（Mint 自带的 p7zip-full），密码用 AES-256，7z 格式还会把文件名一起加密，zip 的文件名仍可见。注意：7z 运行期间密码会出现在它的命令行参数里，本机其他用户用 ps 能看到，file-roller 也是这样做的。和复制一样在状态栏显示进度、可取消（取消会删掉写了一半的压缩包），完成后选中新压缩包。符号链接按链接本身存入，不跟随 |
| 解压 | 右键压缩包选"解压到此处"（多选时全是压缩包也可以）；压缩包上不再出现"压缩…"，混合选择时则只有"压缩…"。zip / 7z / rar / 单个 .gz .xz 等交给 `7z` 解，tar 及 tar.gz / bz2 / xz 用 Python 的 tarfile 一步解开。先解到旁边的隐藏临时目录：里面只有一项就直接挪出来，多项则装进以压缩包命名的文件夹，不会把文件撒在当前目录，也不覆盖已有文件（同名加"副本"）。遇到加密包会弹框要密码，密码错了再问一次；tar 里指向目录外的条目会被拒绝并提示。进度、取消和复制一样，取消后临时目录即删除 |
| 移到回收站 | 右键菜单或 Delete 键，不确认 |
| 永久删除 | 右键菜单"删除"或 Shift+Delete，会先确认；目录递归删除 |
| 回收站 | 从侧边栏进入 Trash 后，右键菜单变为"还原 / 彻底删除"，空白处可"清空回收站"；Delete 键在这里是彻底删除，不能重命名 |
| 最近使用 | 侧边栏 Recent 里列的是 `recent:///` 下的虚拟条目，移到回收站（Delete 键、右键菜单、拖到回收站）和永久删除都作用在条目指向的真实文件上，确认框和报错里显示的也是真实文件名；文件没了，条目随即从列表里去掉。右键菜单另有"从最近使用中移除"（和 Nemo 一样）：只把条目从最近使用列表里去掉，文件本身不动，不确认。列表本身是桌面的“最近使用”记录（`~/.local/share/recently-used.xbel`），所有 GTK 程序共用，和 Nemo 的“最近”是同一份：谁打开或保存了文件谁往里登记，Finch 只是显示它。很多程序（浏览器、非 GTK 程序）从不登记，所以 Finch 自己在打开文件时登记一次（双击、回车、右键“打开”和“打开方式…”选定的程序启动成功之后；文件夹不登记，回收站里的文件不登记），和 Nemo 的做法一样。是否记录、保留多少天由系统设置“隐私”决定（`org.cinnamon.desktop.privacy` 的 `remember-recent-files` 和 `recent-files-max-age`），超过天数的条目由 GTK 在下次写入时清掉；文件已不存在的条目和文件夹不显示。从 Recent 里打开文件时，交给程序的是真实文件而不是虚拟条目（不认 gvfs 的程序也能打开）。Recent 里的图片、视频、APK 和别处一样有缩略图（分栏的行图标、图标视图、预览栏的大图和分辨率等信息），取的是真实文件的缩略图，和它所在文件夹里的那一份共用缓存 |
| 网络 | 侧边栏最下面的 Network 分区里有一行 Network（和 Nemo 一样），点它列出局域网里发现的电脑和 NAS（`network:///`，由 gvfs 提供，和 Nemo 看到的相同）。这些条目以及服务器里的共享不是文件夹而是指向另一个地址的入口：单击只选中，预览栏显示它指向的地址；双击、右方向键、Ctrl+O 或右键"打开"才进入，中键或右键"在新标签页中打开"则开新标签页。这样用方向键在列表里走动不会挨个去连接。进入一个还没连接的地址（从 Network 进去、在地址栏输入 `smb://服务器/共享`、点远程书签、启动参数都算）时自动挂载：栏里先显示"正在连接…"，需要密码就弹出 GTK 的认证对话框（可选记住密码，存在系统钥匙串里），连上后列出内容；取消对话框显示"未连接"，其他失败原因直接显示在栏里，F5 重试。连上的共享由 gvfs 挂载，和 Nemo 共用，之后在侧边栏的设备分区里出现并可弹出。地址栏和标题里服务器或共享的顶层显示挂载的名字。共享上一般没有回收站，Delete 会报错，用 Shift+Delete 永久删除 |
| 在 Nemo 中打开 / 显示 | 右键菜单，或 F4 在终端中打开当前目录 |
| 其他程序里的"打开文件夹" | 浏览器的"在文件夹中显示"、飞书的"打开文件夹"这类功能不走默认程序设置，而是通过 D-Bus 找占有 `org.freedesktop.FileManager1` 这个名字的程序。`finch --service` 就是占这个名字的后台进程：没有窗口，收到请求就启动一个普通的 Finch，打开文件所在的文件夹并选中它。它作为 systemd 用户服务运行：`cp output/finch-filemanager.service ~/.config/systemd/user/`，再 `systemctl --user enable --now finch-filemanager.service`。Cinnamon 下 nemo-desktop（画桌面图标的进程）登录时也会要这个名字，先到先得；systemd 用户服务比桌面会话启动得早，所以之后每次登录都是 Finch 拿到。第一次启用时名字还在 nemo-desktop 手里，注销重新登录一次（或重启 nemo-desktop）后生效；服务没在运行时这些请求仍由 Nemo 处理。命令行上 `finch 某文件` 打开它所在的文件夹并选中它，`finch --select 某文件夹` 则在上一级里选中这个文件夹 |
| 关于 | 右上角菜单最底下的"关于 Finch"，显示版本号 |
| 标签页 | Ctrl+T 在新标签页打开当前目录，Ctrl+W 关闭当前标签页（最后一个关闭窗口），Ctrl+Tab / Ctrl+PageDown 和 Ctrl+Shift+Tab / Ctrl+PageUp 切换；右键文件夹选"在新标签页中打开"、中键点击文件夹、中键点击侧边栏位置都在后台开新标签页。只有一个标签页时不显示标签栏，标签可拖动排序；把标签拖离标签栏松手就变成一个新窗口（落在文件列表、文件夹、预览栏等窗口内的其他地方也一样，不会被当作文件拖放），只有拖进另一个 Finch 窗口的标签栏才会并入那个窗口；拖走最后一个标签的窗口自动关闭。每个标签页有自己的栏、预览和前进 / 后退历史；栏宽、隐藏文件、排序方式是全局的，对所有标签页生效。启动时总是打开一个主目录标签页，不记住上次的位置；命令行给多个目录则各开一个标签页 |
| 拖拽 | 把文件拖到另一栏（空文件夹显示的"空文件夹"页面也算）、某个目录行或侧边栏的位置上即移动过去，按住 Ctrl 为复制；拖到回收站（栏或侧边栏的 Trash）即移到回收站。目标目录行会高亮，整栏作目标时整栏变色；拖回原目录、拖进自身不接受。也可以在 Finch 和 Nemo 等程序之间拖拽 |

左侧是 GTK 自带的"位置"侧边栏，书签、挂载的设备、已连接的网络共享都在里面，最下面是 Network 分区（浏览局域网），
和 Nemo 共用同一份书签。每个分区有标题；已挂载的设备名下有一条空间占用条，
